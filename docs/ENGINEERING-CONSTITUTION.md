# MusicClean Orion Engineering Constitution

**Status:** Accepted

> Collect evidence. Build confidence. Preserve music.

1. The user's collection is the asset.
2. Domain and application logic remain independent of concrete infrastructure.
3. Evidence precedes Knowledge.
4. Knowledge precedes Decisions.
5. Decisions are explainable and reproducible.
6. Analysis and recommendation never directly delete media.
7. Stable identity is independent of filesystem location.
8. Major architectural decisions require ADRs; significant proposals use RFCs.
9. Correctness and regression safety outrank feature velocity.
10. Performance regressions against established budgets are defects.
11. Public contracts evolve deliberately with migration guidance.
12. Architectural documentation changes with the architecture.

## Quality gates

Applicable changes must pass Ruff, MyPy, Pytest, regression tests, documentation review, migration tests, and performance review.
